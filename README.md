# azurpromilia-switcher

《蓝色星原：旅谣》多区客户端共存工具。每个区保留独立客户端目录，相同文件用硬链接共享，只下载差异部分。

三区 239.70 GiB → 132.81 GiB ｜ 图形界面 ｜ 写入有账本，可回滚

## 三步开始

1. 安装 Python 3.11+，安装时勾选 **Add python.exe to PATH**
2. 双击项目目录下的 `start-gui.cmd`
3. 浏览器打开后：选源区 → 选目标区 → 计算计划 → 开始执行

已经装好一个区的客户端，直接把它当源区。还没有客户端时，先装官方启动器：界面会显示「打开启动器安装包」或「打开官网安装」，装完点「重新检测」。

## 需要准备什么

- 一个已装好的客户端作为源区（约 79 GiB）
- 目标区与源区在**同一个 NTFS/ReFS 分区**，跨分区无法建立硬链接
- 目标区预留约 30 GiB；已有且大小一致的文件不会重复下载

## 界面能做什么

- 客户端卡片：国服（卡片内切换官服 / 哔哩哔哩服）、台服、日服
- 计算计划：只读，不写客户端目录
- 开始执行：建硬链接、下载差异、写启动器索引、校验并修复
- 维护：补丁状态、按清单修复、账本回滚
- 高级功能：全量校验/修复、预览删除、清理失效账本、提取渠道源

## 常见问题

**没有检测到客户端**
先安装任意一个区的官方启动器，装完点「重新检测」。装在其他位置时，展开「启动器装在其他位置」，填写启动器 exe 或安装目录；保存后下次仍会自动检测。

**目标区显示「需先安装启动器」**
点「打开启动器安装包」或「打开官网安装」，装完重新检测。

**国服卡片显示「B服源 缺失」**
官服 / B 服切换需要各自的渠道源。先在当前渠道点「提取当前渠道源」，再到另一渠道的客户端里提取一次。

**计算计划后要下载几十 GiB**
确认目标目录选对；已有且大小一致的文件会显示为「已就绪」，不会重复下载。

**提示跨卷 / 无法建立硬链接**
源区和目标区不在同一个分区，把目标区换到与源区相同的盘。

**界面打不开**
查看 `start-gui.cmd` 窗口的报错；端口被占用时用 `python -m azp gui --port 8790`。
